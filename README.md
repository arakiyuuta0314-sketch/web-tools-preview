# 開発中アプリのWebリンク集

総合ページ： https://arakiyuuta0314-sketch.github.io/web-tools-preview/

目的は、開発中・試作済みのアプリを自分でまとめて開くことです。
**公開向けの紹介サイトや作品展示場ではありません。** 旧版・画像比較などの別リンクを総合ページに載せず、各アプリにつき現在の入口を1件だけ掲載します。

## アプリを増やす・最新版へ更新する場合

1. 各アプリのWebプレビューの動作する入口URLを確認します。
2. app-catalog.json の entries にアプリ名・URL・開発状況を追加／更新します。
3. python build-portal.py で index.html を再生成します。重複ID・存在しないローカルリンクはエラーになります。
4. スマホ・PCでシンプルな一覧が表示されるか検証し、GitHub Pagesへ反映します。

一覧はアプリ名、開発状態、1つのリンクだけ。長い説明・比較版・過去版・広報用コピーは表示しません。

## Web版とiOS版

現在はWebで機能を試作してiOSへ対応していく開発手順を利用していますが、**Web版を最終的に一般公開・継続運用するかどうかは未決定**です。
iOSの広告・課金・通知・画面向き・保存・権限などはWebだけでは検証できません。

注意：このGitHub Pagesのリンク集そのものはURLを知っている人なら閲覧できます。検索エンジンにはnoindexを指定していますが、アクセス制限はありません。個人情報・秘密の認証情報・ユーザーの写真は配置しないでください。

app-index.js は旧バージョンの検索UIで使用したファイルで、新しい簡易一覧からは読み込まれません。
build-preview.mjs は個別プロジェクトのスナップショットを手動生成する別の仕組みで、総合ページ生成時には使いません。

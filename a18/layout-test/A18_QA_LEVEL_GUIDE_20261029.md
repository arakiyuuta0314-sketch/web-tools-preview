# A18｜開発用レベル切替・展示室5（2026-10-29）

## 展示数とレベル
- 部屋ID 0（エントランス）3枠、ID 1〜4（展示室1〜4）各5枠、ID 5（展示室5）3枠。合計26枠。
- 館Lv.1〜6、部屋ID、接続経路、既存イベントIDは変更しない。
- 展示室5を3枚埋めると、従来の `gallery06-complete-v1` を発生させる。Lv.7は作らない。
- 旧v3セーブに残る `frame-5-3` と `frame-5-4` は読み込み時に正規の26枠形式へ移行。該当枠の作品は **作品そのものを削除せず** 保管中へ戻し、原本Blob・メモを保存する。移行はrevision競合検査付きのIndexedDBトランザクションで行う。

## 開発用の操作
1. **開発ビルド**の `a18/layout-test/index.html?qa=1` を開く。通常のURLにはQA機能を表示しない。
2. 初回は館長名などを設定し、案内を閉じる。
3. 右下の歯車から「設定」→「開発テスト（QA専用）」を開く。
4. 館 Lv.1〜6を選び「レベルを切り替える」。開放済みのエリア間を実際に歩いてテストする。
5. 入室中の部屋が新しいレベルで施錠対象になる場合は、安全のためエントランスへ戻す。

QAセーブは同じIndexedDB内の独立した `museum-qa` キー。通常プレイの `museum` キーは変更しない。QA中は画面上に `[QA]` と表示する。レベル切替時、開放済みの過去イベントは閲覧済みとして再構築し、イベント演出を再生せず移動を試せる。レベル変更はQAセーブに永続化され、再読込でも維持される。

※URLに `?qa=1` を付けるだけでは一般公開版の現行動作は変わらない。ソースをデプロイして初めて利用できる。公開・正式版への統合は別途指示が必要。

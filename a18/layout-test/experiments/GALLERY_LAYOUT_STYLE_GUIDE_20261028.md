## 2. 共通部品と「変えてよいもの」
**共通**：深緑の展示面、濃いオーク材の柱・腰壁・額縁、明るい石床、2D斜め見下ろし型として自然な水平壁面、額縁前への到達、奥側の通路と接続位置の整合性。

**自由**：各展示室の幅/奥行き、展示面の数、独立展示壁の向き・大きさ・前後位置、出口の位置（ただしエントランスからの確定接続は守る）、回遊の分岐、施設の有無。エリアごとに別の空間体験を優先し、全室を同じ形にしない。画面スクロールは変化を出す手段の一つであり、移動負荷の増加を避ける。

**まだ検討しないもの**：スタッフ、Lv別の装飾・照明・家具細部、写真登録UI、追加ギミック、視点回転機能。施設の名称・役割はその部屋の設計後に決める。

## 5. 将来の本実装に必要な工程
1. 監修でA/B/調整案の採否を確定する。
2. 承認した建築壁・床・独立壁の素材を**独立レイヤー**として正式化する。今回の一枚画像のままゲームに使わない。

4. エントランスLv.1や他室の正式素材を変更しない。ゲーム実装が決まるまで、現行公開版も維持。
5. 実際のChromeで画面サイズ別・入退室・鑑賞・保存回帰を検証してから採用する。

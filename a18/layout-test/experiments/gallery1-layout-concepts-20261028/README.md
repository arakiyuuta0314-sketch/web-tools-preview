# B型：エントランス側入口の2案（2026-10-28）

採用候補となったB型を保ちながら、出入口位置だけ比較。部屋内の展示作品数は5枠。

- **B1_planned**：展示室1の右奥にエントランス側入口。エントランスでは左の仕切り壁の裏から左方向へ進むという確定構想と、部屋の相対位置が自然につながる。展示室1の左奥には次のエリアへ向かう出口を仮置き。
- **B2_diagonal**：右手前の旧入口を維持。右端を奥へ進み、背面の通路を横切って左奥の出口に向かう。エントランスの左裏から右手前の入口に到着させるには、両室の間に折れ曲がった連絡通路を想定する必要がある。

両案ともP3の実素材を使った**静止画合成**。壁は元のBと同様に2枚の独立壁をずらした構成、配置は通路幅を確保する意図で試験的に調整。奥壁の3枠と独立壁の2枠を維持。奥の出口が実際にどの展示室につながるかは**未決定**。

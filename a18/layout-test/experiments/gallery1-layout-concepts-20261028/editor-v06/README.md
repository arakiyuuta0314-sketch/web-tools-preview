## プレビューの使い方
- `index.html` をブラウザで開くか、ホスト環境で静的に配信する。`editor.js` と4つのPNGは同じディレクトリに置く。
- **単一HTML版 `gallery1-layout-editor-v06-offline.html` は画像とスクリプトを内蔵**。PCのブラウザで直接開く。Google Driveのファイル閲覧画面ではスクリプト実行が制限されるため、**ファイルをダウンロードしてブラウザで開く**。
- スマホ向けに390px幅のChromeで検証済み。iPhoneの「ファイル」アプリ内プレビューはJavaScriptを無効化する場合があるため、動かない場合はPCブラウザを使うか、別途Webプレビュー公開が必要。
- 画面は横へスクロール。選択した展示壁④・展示壁⑤・案内台だけドラッグで変更可能。
- X/Y数字入力で1px単位に調整。ボタンで±1または±10、矢印キーにも対応。
- 自動保存は**今開いているブラウザのみ**。ブラウザを変えると共有されない。座標をJSONでコピー/保存、別端末で読み込める。
- 重なりや壁の範囲からの逸脱は警告のみ。現段階では自由配置を重視して自動再配置は行わない。

## 配置とゲーム本体の関係
- 930×582の**監修用の静的建築画像**を基礎にする。奥壁・出入口・側壁は移動不可。
- ゲーム本体の保存、進行、作品展示枠5つ、当たり判定、カメラ追従、正式素材は変更しない。
- エディターのJSONはゲームの保存データではない。採用後に専用の実装・実機QAが必要。
- 生成コマンド：`python build_assets.py`、`python build_portable.py`。
- 品質検証：`python qa_editor.py`（PC 1180px / スマホ390pxのChromeでドラッグ、座標、履歴、ローカル保存、JSON検証、画像読み込みを確認）。
